# 🌱 EcoTrend - E-commerce Sustentável

E-commerce especializado em produtos sustentáveis e ecológicos, focado em promover um estilo de vida mais consciente e sustentável.

## 🛍️ Tipos de Produtos

- Roupas e acessórios sustentáveis
- Produtos de beleza e cuidados pessoais naturais
- Itens para casa sustentáveis
- Tecnologia verde

## ✨ Funcionalidades

- **Carrinho de compras dinâmico**: adicione produtos ao carrinho com atualização instantânea, exibido em um drawer lateral.
- **Persistência com `localStorage`**: os itens do carrinho permanecem salvos mesmo após fechar e reabrir o navegador.
- **Carregamento de produtos via JSON**: a lista de produtos é carregada de um arquivo JSON (Fake API) com `fetch`.
- **Requisições assíncronas**: uso de `async/await` com loading spinner durante o carregamento.
- **Checkout simulado**: finalização de compra com `promises` e feedback de sucesso/erro.

## 🛠️ Tecnologias

- **React** - Framework para construção da interface
- **Tailwind CSS** - Estilização
- **JavaScript (ES6+)** - Manipulação do DOM, Promises e `async/await`

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Off-Grid-Team/Checkpoint-4-Web.git
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```
